💾 INSTALLATION BY PLATFORM
================================================================================

WINDOWS:
    1. Download finanflow-web-app.zip
    2. Right-click → Extract All
    3. Double-click start-server-windows.bat
    4. Browser opens automatically
    5. Done!

macOS:
    1. Download finanflow-web-app.zip
    2. Double-click to extract
    3. Right-click start-server-macos-linux.sh → Open
    4. Grant permission if prompted
    5. Browser opens automatically
    6. Done!

LINUX:
    1. Download finanflow-web-app.zip
    2. Extract: unzip finanflow-web-app.zip
    3. Right-click start-server-macos-linux.sh → Run
    4. Or run: bash start-server-macos-linux.sh
    5. Browser opens automatically
    6. Done!

iPHONE/iPAD:
    1. Open Safari
    2. Visit: https://fflow-phi.vercel.app/
    3. Tap Share (arrow up) → Add to Home Screen
    4. Name: FinanFlow
    5. Tap Add
    6. Done!

ANDROID:
    1. Open Chrome
    2. Visit: https://fflow-phi.vercel.app/
    3. Tap ⋮ (menu) → Install app
    4. Confirm
    5. Done!
